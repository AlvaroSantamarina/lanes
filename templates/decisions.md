# Decisions

Record of the project's decisions (D1 onwards). **If something here contradicts the code or another source, this file wins:** fix the code, or stop and ask.

To add one: a `### D<n>` block at the end of section 1, dated, in the same PR that applies it. Numbers are reserved by the coordination session in `docs/memory.md`; use the one your start prompt gives you.

## How to read this file

- **Section 1:** closed technical decisions. Briefs cite the ones that apply.
- **Section 2:** business rules from the owner or the business side.
- **Section 3:** what is still open, each item with a **provisional assumption** so work does not stop.
